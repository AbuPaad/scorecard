JavaScript Fun Facts Flashcards

What is NaN?
NaN means "Not a Number". It's a value that comes from invalid math.
Does JS have classes?
Yes, JS has classes but they are just syntax over prototypes.
What is typeof null?
typeof null returns "object" which is a known bug in JS.
What is hoisting?
Hoisting moves declarations to the top of their scope.
What is === vs == ?
=== checks value and type. == does type coercion.
Can JS run in browser?
Yes, JavaScript was made to run in web browsers.
What is a closure?
A closure is a function that remembers variables from its outer scope.
Is JS single threaded?
Yes, JavaScript is single threaded but uses event loop for async.
